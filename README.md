# Patrick Naufel — Website

Site pessoal de Patrick Naufel — **Design & Product Strategist**.

## Desenvolvimento

```bash
npm install
npm run dev
```

Stack: React, Vite, TypeScript e Tailwind CSS 4.

## Publicação

Importe este repositório na Vercel. Framework preset: **Vite**; build: `npm run build`; output: `dist`.

## Imagem de capa

A fotografia integrada e sem logotipo está incluída em `public/patrick-hero.webp` e é carregada diretamente pela homepage.

## Conteúdo

As seções e informações ficam em `src/App.tsx`. Os estilos estão em `src/index.css`. Os contatos são links externos (sem formulário ou coleta de dados).
